# 📂 File Handling Project in Python

Welcome to the **File Handling Project** 🚀  
This repository contains beginner-friendly Python programs demonstrating different file handling operations.

The project helps in understanding how files work in Python using practical examples.

---

# 🛠️ Topics Covered

- Creating files
- Reading files
- Writing into files
- Appending data
- File modes
- Working with text files
- Using `with open()`
- File closing handling
- Exception handling in files

---

# 📁 Project Structure

## `create_file.py`
Program to create the new file.

---

## `read_file.py`
Reads data from a file.

---

## `write_file.py`
Writes content into a file.

---

## `append_file.py`
Appends new content without deleting old data.

---

## `file_modes.py`
Demonstrates different file modes:

- `r`
- `w`
- `a`
- `x`

---

## `exception_handling.py`
Handles file-related errors safely.

---
